# Agradecimientos

Si este texto y la versión en inglés difieren, prevalece el inglés.

Agent KBase se apoya en código abierto y en servicios gestionados que agradecemos.

## Software del proyecto

La CLI, la librería core, las plantillas, el servidor MCP y la web viven en [github.com/m-qm/project-brain](https://github.com/m-qm/project-brain). La licencia está en ese repositorio.

## Aplicación web

* [Next.js](https://nextjs.org/) (framework de React)
* [React](https://react.dev/)
* [Vercel Analytics](https://vercel.com/analytics)

## Ecosistema que documentamos y con el que integramos

* [Cursor](https://cursor.com/) (editor de agentes)
* [SkillTree](https://skilltree.ai/) (skills y auditorías; producto aparte)
* Patrones opcionales de memoria Engram, documentados en las guías (Engram es opcional y no hace falta para el uso de código abierto)

## Correo y alojamiento

* [Vercel](https://vercel.com/) (alojamiento)
* [Resend](https://resend.com/) (lista de espera y email transaccional, cuando está activo)

## Lista completa de dependencias

Para versiones y licencias exactas de los paquetes npm, véanse `pnpm-lock.yaml` y los `package.json` del monorepo, o pasa la auditoría de código abierto de tu organización sobre el repositorio.

Los nombres y logotipos de terceros son de sus dueños. Agent KBase no está respaldado por Cursor, Anthropic, OpenAI ni SkillTree salvo que se diga por escrito.
