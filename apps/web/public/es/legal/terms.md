# Términos del servicio

Si este texto y la versión en inglés difieren, prevalece el inglés.

**Última actualización:** noviembre de 2026

Estos términos se aplican a **agentkbase.com**, el asistente web, la lista de espera y las páginas relacionadas. El software de código abierto del repositorio tiene además la licencia de ese repositorio (véase Agradecimientos).

## Quién opera la web

La web la opera la **persona que mantiene** el proyecto de código abierto Agent KBase (**hello@agentkbase.com**). Aquí todavía no se identifica una sociedad. «Nosotros» o «quien opera» es esa persona en tanto que lleva esta web y la lista, no una empresa, salvo que se diga en el pago.

## Uso de la web

Aceptas usar la web de forma legal y no abusar de los endpoints (incluido el raspado automático de rutas de LLM, el spam de la lista o saltarse los límites).

El asistente y la CLI sirven para construir **bases de conocimiento para agentes** en tus repos. Tú respondes de que los hechos que exportas sean ciertos y de cómo actúan los agentes con ellos.

## Lista de espera y ofertas previas al lanzamiento

Los workers de contenido y anuncios, los conectores Act y las ofertas relacionadas pueden describirse antes de estar disponibles. Apuntarte a la lista **no** crea un contrato de venta a un precio concreto. El alcance, el precio o el calendario pueden cambiar hasta que exista un **pago o un acuerdo escrito** con un vendedor identificado (que puede ser una empresa registrada más adelante).

## Software de código abierto

El código de la CLI y de la librería se ofrece **tal cual**, sin garantía, en la medida que permita la ley. Véase el archivo LICENSE en [github.com/m-qm/project-brain](https://github.com/m-qm/project-brain).

## Aviso del servicio alojado

El asistente gratuito y la documentación se ofrecen con el **mejor esfuerzo**. Las expectativas de disponibilidad están en [Nivel de servicio](/legal/sla). Las compras de hecho-para-ti o de packs, cuando existan, tendrán términos aparte en el momento de la compra.

## Propiedad intelectual

El nombre Agent KBase, el diseño de la web y la documentación se mantienen para el proyecto de código abierto. El copyright del software sigue la LICENSE del repositorio. Las marcas de terceros (Cursor, SkillTree, Vercel, etc.) son de sus dueños.

## Límite de responsabilidad

En la medida máxima que permita la ley, quien opera la web no responde de daños indirectos, incidentales o consecuentes por el uso de la web o del contenido exportado del brain, incluidas las acciones de un agente en tu entorno.

## Ley aplicable

Donde haya normas **imperativas** de consumo o de protección de datos en tu país, esas normas se aplican en lo que exijan. En lo demás, las disputas se plantean de buena fe en **hello@agentkbase.com** antes de otra vía.
