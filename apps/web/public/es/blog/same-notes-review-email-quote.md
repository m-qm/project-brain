# Cómo contestar una reseña, un correo y un presupuesto con la misma información

La reseña, el correo y el presupuesto pueden salir de tres borradores distintos. Cada uno puede rellenar un hueco con un precio, un cliente o una fecha que nadie escribió. Luego el cliente pide que lo cumplas.

## Qué puede salir de las mismas notas

Las notas dicen qué vendes, para quién y qué sigue en `[CONFIRMAR]`. Con eso se puede preparar:

1. Una reseña de Google tranquila, con líneas que ya aprobaste. Una reseña de una estrella, un reembolso o un precio que no está escrito esperan tu sí.
2. Un correo o un mensaje del formulario, con esas mismas líneas. Una petición que las notas no contestan espera.
3. Un texto de LinkedIn, cuando el artículo ya está publicado.
4. Un presupuesto corto, o el brief de una llamada. Un precio que falta se queda marcado.
5. Una parada antes de enviar. Si el borrador nombra un precio que las notas no tienen, no sale.

## El ejemplo de la reseña

En la home, la reseña tranquila usa el nombre Ana: «Objetivos semanales claros. Gracias.»
El borrador dice: «Gracias, Ana. De la carpeta: qué vendes y para quién.»

La reseña de una estrella usa el nombre Luis: «Una estrella. Quiero un reembolso.»
No se publica. La sugerencia es: «Gracias, Luis. Te respondo yo.» Te llega un aviso.

Esos dos nombres son los del dibujo de la home. No son un cliente publicado.

El hueco de precio está en el otro artículo. La web decía «a consultar». El borrador escribió «desde 99 €». Esa línea queda en Precio: `[CONFIRMAR]`.

## Lo que sigues haciendo tú

Lees el borrador y dices que sí antes de que salga. Un dato nuevo entra en la carpeta por el asistente, la página donde pegas tu web. El siguiente borrador ya puede usar esa línea. Decir que sí a una reseña no cambia la carpeta.

## Cómo se lee la carpeta

Agent KBase guarda las notas en git. Git es el historial de cada cambio. Mastra es el programa que encadena la lectura y el borrador. Los pasos están en [Encadenar el borrador](/learn/13-mastra).

## Para quién es

Para un negocio con web y sin equipo de marketing. Una tienda, un estudio o una consultoría pequeña.
