# Modo aplicación (opcional)

Un brain de carrera o de ventas usa el mismo esquema:

* `brain/facts/experience.md` con roles fechados
* `brain/stories/` para sistemas en producción
* `brain/open-questions.md` para métricas que te niegas a inventar
* Un módulo opcional de reglas de escritura para textos de cara a quien contrata

No subas secretos ni datos confidenciales de un empleador a un repo público. Guarda un brain privado y exporta solo plantillas ya limpias.
