# Application mode (optional)

A career or sales brain uses the same layout:

* `brain/facts/experience.md` dated roles
* `brain/stories/` for production systems
* `brain/open-questions.md` for metrics you refuse to invent
* Optional writing rules module for employer facing copy

Do not commit secrets or confidential employer data to a public repo. Keep a private brain repo and export sanitized templates only.
